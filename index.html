How it works

Three steps. Zero tab-hopping.

  1. 01

    Pick a file

    Photos up to 20 MB (including HEIC, converted in your browser), or MP4/H.264 videos up to 500 MB. A thumbnail is captured client-side, so you preview exactly what goes out.

  2. 02

    Stage it

    Your file uploads straight to a private Supabase Storage bucket via a signed URL, so there are no server body-size limits and no middleman.

  3. 03

    Publish

    Dandela calls each platform’s API, writes one log row per attempt, and always deletes the staged object afterwards, success or failure.

Security

Your accounts, kept honest.

Dandela is a single-user app: you own the keys. Tokens are sealed at rest with pgsodium, released only through scoped database RPCs, and your staged media is purged the moment a publish finishes.

  • Tokens encrypted at rest (AEAD via pgsodium)
  • Credentials never exposed to the client
  • Staging objects deleted after every attempt
